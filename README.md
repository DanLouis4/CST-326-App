# CST-326-App

RPG Character Tracker web application for CST-326.

## Technology Stack
- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- Bootstrap
- Spring Data JPA
- Spring Security
- MySQL

## MVP Features
- User registration and login
- Character creation, viewing, editing, and deletion
- Character search and filtering
- Basic role-based access control
